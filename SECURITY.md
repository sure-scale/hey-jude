# Security Policy

Hey Jude keeps real PII out of cloud LLMs, so a bug can leak sensitive data.

## Reporting

**Don't open a public issue, PR, or Discussion.** Report privately via
[GitHub Security Advisories](https://github.com/sure-scale/hey-jude/security/advisories/new).

A privacy leak — un-anonymized text reaching a provider, or PII exposed in logs
or responses — is a security report, not a normal bug.

Include: what the issue is, steps to reproduce **with synthetic data only**, and
the affected version.

We aim to acknowledge within 3 business days and will credit you on a fix unless
you prefer otherwise. Please allow time for a fix before public discussion.

## Supported versions

Pre-1.0: fixes land on `main`. Pin to a commit and upgrade forward.
